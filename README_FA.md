# نسخه ۲۰ درمان‌گر — نام کاربری و رمز عبور

روش ورود این نسخه: ثبت‌نام و ورود با نام کاربری و رمز عبور شخصی، بدون OTP پیامکی. نام کاربری ۴ تا ۳۲ نویسه از حروف انگلیسی کوچک، عدد و زیرخط است. رمز عبور حداقل ۱۰ نویسه و شامل حرف و عدد است؛ هش رمز با PBKDF2-SHA-256 و salt مستقل ذخیره می‌شود. پس از ۵ تلاش ناموفق، ورود برای ۱۵ دقیقه قفل می‌شود.

## راه‌اندازی پایگاه داده
این نسخه به schema تازهٔ تعریف‌شده در `schema.sql` نیاز دارد، چون ساختار جدول کاربران تغییر کرده است. قبل از هر تغییری در D1 موجود، از داده‌ها نسخهٔ پشتیبان بگیرید؛ اجرای schema تازه روی پایگاه دادهٔ دارای داده می‌تواند به تعارض جدول‌ها منجر شود. برای پایگاه دادهٔ موجود، ابتدا باید مهاجرت کنترل‌شده طراحی و اجرا شود.

## تنظیمات Worker
- متغیر `SESSION_SECRET`: رشته تصادفی محرمانه با حداقل ۳۲ نویسه.
- اتصال D1 با نام `DB` در `wrangler.toml`.
- انتشار Worker و فایل‌های static باید مطابق ساختار پروژه انجام شود.

## محدودیت مهم
ثبت‌نام عمومی با انتخاب نقش requester/provider در این نسخه فعال است. حساب provider به‌تنهایی به معنی تأیید صلاحیت حرفه‌ای نیست؛ برای استفادهٔ واقعی باید دسترسی ارائه‌دهندگان تا زمان بررسی مدارک و تأیید مدیر محدود شود. این نسخه هنوز نباید بدون آزمون کامل و تنظیم دامنه/HTTPS و سیاست‌های عملیاتی در محیط عمومی استفاده شود.
